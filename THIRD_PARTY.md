# Dependencies and provenance

- `third_party/xbr`: Hyllian's xBR-lv3 shader, copyright 2011-2015, MIT. Its contour rules are adapted for offline CPU processing in `src/gt2formats/ui_contours.h`. The upstream shader, licence, retrieval URL and SHA-256 are retained in this folder. No xBR neighbourhood search runs during gameplay.

- `third_party/openxr`: Khronos OpenXR headers; see the bundled `third_party/openxr/LICENSE`. Android packages `org.khronos.openxr:openxr_loader_for_android:1.1.43`, obtained from Maven Central under Apache-2.0. Windows player releases bundle the x64 loader built from [Khronos OpenXR SDK Source 1.1.58](https://github.com/KhronosGroup/OpenXR-SDK-Source/tree/release-1.1.58), also Apache-2.0. Its statically linked JsonCpp retains its MIT/public-domain notice in `third_party/openxr/JSONCPP-LICENSE.txt`. Both notices are included in player packages; the DLL is not part of the source kit.
- Android SDK/NDK, Gradle and Android Gradle Plugin are external build dependencies. NativeActivity glue is compiled from the installed NDK under its Apache-2.0 license. None of their toolchain binaries or build caches belong in the source repository.
- The portability and stereo renderer work was integrated from the existing Gran Turismo 2 PC project. Android lifecycle, Touch input and deployment share this repository's game implementation. The Android overlay uses a small in-code bitmap alphabet; Windows keeps its system-font rendering.
- Vulkan headers, loader and `glslc`: provided by the separately installed [Khronos/LunarG Vulkan SDK](https://vulkan.lunarg.com/). No SDK binaries are included in the source archive. The WinGet package is [KhronosGroup.VulkanSDK](https://github.com/microsoft/winget-pkgs/tree/master/manifests/k/KhronosGroup/VulkanSDK).
- CMake, Microsoft Visual Studio C++ Build Tools and optionally 7-Zip are installed through WinGet, under their respective licenses. The supported C++ workload is [Microsoft.VisualStudio.Workload.VCTools](https://learn.microsoft.com/en-us/visualstudio/install/workload-component-id-vs-build-tools?view=vs-2022).
- DualSense HID packet layout/transport facts were checked against the [SDL PS5 driver](https://github.com/libsdl-org/SDL/blob/main/src/joystick/hidapi/SDL_hidapi_ps5.c) and [Joystick Input Examples protocol documentation](https://github.com/MysteriousJ/Joystick-Input-Examples). The project's encoder and Win32 output worker are newly written; those implementations are not vendored. Effects use feedback mode 0x21 and release mode 0x05, bounded ten-zone forces, and the Bluetooth HID output CRC prefix 0xA2.
- The PC overlay rasterizes the user's installed Windows system font at runtime. No font, game artwork, original executable, BIOS, disc image, media, decompiler output or RAM capture is added by this change.

The existing reverse-engineering provenance is recorded in `db/`, `re/` and `docs/formats/`. This file is a dependency inventory, not a grant of rights to third-party game content or a replacement for the project's own distribution license.

Windows HID report padding was checked against [HIDAPI's Windows backend](https://github.com/libusb/hidapi/blob/master/windows/hid.c); DualSense USB/Bluetooth descriptor sizes were checked against [nondebug's device descriptors](https://github.com/nondebug/dualsense). These are protocol references; their source is not included.

- `third_party/vrhands`: the same UltimateXR hand meshes and four authored finger poses used by MiamiVR Quest, plus its skin-colour texture. Copyright VRMADA, MIT License; see `ULTIMATEXR_LICENSE.txt` and `SOURCE.md`. These are redistributable VR assets, not GT2 or GTA assets. The build embeds them in the executable so an APK update needs no game-data replacement.
- Virtual-wheel and motion steering, hand basis and pose blending are shared with the same author's MiamiVR Quest project (`QuestDrivingVR.cpp`, `VRHandModel.cpp`, `vrhands_quest.cpp`), under the MIT License recorded in `third_party/vrhands/MIAMIVR_LICENSE.txt`. GT2 supplies its own camera, rendering and original vehicle physics/replay integration.

Player releases include dependency notices under LICENSES/, including the Android NDK/runtime and OpenXR loader licences. The installer can download Google's pinned Platform Tools 36.0.2 archive; it retains Google's NOTICE.txt and source.properties in its tool cache. These tools are not bundled in the source folder.

- `third_party/stb`: unmodified stb_image 2.30 (JPEG decoding) and stb_image_write 1.16 (offline JPEG encoding), Sean Barrett and contributors, MIT or public domain. This project uses the MIT option. Exact retrieval URLs and SHA-256 hashes are in `third_party/stb/SOURCE.md`; licence in `LICENSE.txt`.
- `third_party/libretro/libretro.h`: the libretro API header, RetroArch team, MIT. `SOURCE.md` records the source URL and hash. The offline Windows boot-capture helper and portable Python capture host use this API; the game does not load emulator cores.
- Optional installer download: [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN), Xintao Wang, BSD-3-Clause, via the NCNN Vulkan 20220424 Windows release. The package and models are fetched separately, verified against a pinned SHA-256 and retained in the local installer cache. Upstream [licence](https://github.com/xinntao/Real-ESRGAN/blob/master/LICENSE).
- Optional installer download: [Beetle PSX libretro](https://github.com/libretro/beetle-psx-libretro), GPL-2.0, software core for local BIOS capture only. The core is not bundled. Upstream [source and licence](https://github.com/libretro/beetle-psx-libretro/blob/master/COPYING). Its verified download hash is recorded in `prepare-hd.ps1`; the user supplies the firmware and disc.

- Optional Linux startup capture dependency: [Pillow](https://python-pillow.github.io/), HPND/PIL licence, used only for frame conversion and JPEG encoding. Version 12.0.0 Linux x86_64 wheels for CPython 3.10–3.14 are fetched separately from PyPI using the URLs and SHA-256 hashes in `scripts/linux-downloads.json`. Wheel contents, including their dependency licences, remain in the user's cache. An already installed Pillow can also be used. No Python package binaries are bundled in the release.
- `scripts/gt2_disc.py` implements the same ISO9660/GTFS extraction rules as this project's `DiscImage` and `GtfsVolume`, using Python's standard library. Linux installation requires no Windows executables. The optional Linux core URL and hash are recorded in `scripts/gt2_boot.py`.
